# 壁纸分享应用 -- 产品方案

## 1. 产品定位

面向壁纸爱好者的分享平台，用户可上传、浏览、搜索、下载和收藏高质量壁纸。

### 1.1 动态生成式壁纸（粒子效果）

产品中所称的“粒子效果”是一个面向用户的广义分类，不限于狭义的粒子系统。更准确的定义是**动态生成式壁纸（Generative Wallpaper）**：以程序实时绘制为主要表现方式，由颜色、简单图形、几何图形和模拟效果组成的非实拍壁纸。

它包括但不限于：

- 粒子效果：星空、萤火虫、雪花、烟尘和漂浮光点。
- 自然模拟：雨滴、水波、火焰、云雾、极光和闪电。
- 线条与流体：丝线、光束、流场、波纹和能量轨迹。
- 几何图形：网格、多边形、圆环、隧道和万花筒。
- 色彩效果：渐变、光晕、液态色彩、噪声和呼吸色块。
- 抽象材质：点阵、玻璃、金属、布料和晶体。
- 交互效果：随鼠标、时间、声音或系统状态发生变化的视觉效果。

设计和实现遵循以下原则：

1. 以非实拍、程序生成的视觉内容为核心，不要求使用某一种固定的渲染技术。
2. 以动态效果为主；静态画面可以作为暂停状态、预览封面或少数特殊预设。
3. 参考图片和外部作品用于传达视觉语言、构图、配色与氛围，不代表最终效果必须复刻成固定壁纸。
4. 每一种效果都应是经过设计的完整预设，而不是仅更换颜色或参数的技术演示。
5. 同一种效果可以提供颜色、速度、密度、形态和交互方式等主题变体。
6. 动态表现应适合长期作为桌面背景：运动克制、衔接自然、不干扰前景内容，并控制 CPU、GPU 和能耗占用。
7. 实现时可按效果选择粒子系统、Shader、流体模拟或几何渲染，最终以视觉品质、动态自然度、稳定性和资源占用为判断标准。

## 2. 目标用户

- 桌面 / 手机壁纸爱好者
- 摄影师、设计师（分享作品）
- 需要高质量素材的内容创作者

## 3. 核心功能

### 3.1 用户系统

| 功能 | 描述 |
|---|---|
| 注册 | 用户名 + 邮箱 + 密码 |
| 登录 | 邮箱 + 密码，返回 JWT |
| 个人资料 | 头像、昵称、个性签名 |
| 用户主页 | 展示上传的壁纸、收藏列表 |

### 3.2 壁纸管理

| 功能 | 描述 |
|---|---|
| 上传 | 支持 JPG / PNG / WebP，单文件最大 20MB |
| 元信息 | 标题、描述、分类（单选）、标签（多选） |
| 自动提取 | 分辨率、文件大小、主色调 |
| 异步处理 | 上传后自动生成缩略图（300x200）和预览图（800xAuto） |
| 删除 | 仅作者可删除自己上传的壁纸 |

### 3.3 浏览与发现

| 功能 | 描述 |
|---|---|
| 首页推荐 | 热门（按点赞）、最新（按时间）、精选（编辑推荐） |
| 分类浏览 | 自然、城市、动漫、抽象、极简、科技等 |
| 标签筛选 | 多标签 AND 筛选 |
| 分辨率筛选 | 1080p / 2K / 4K / 超宽屏 |
| 搜索 | 关键字匹配标题和标签 |
| 分页 | 游标分页，支持无限滚动 |

### 3.4 互动功能

| 功能 | 描述 |
|---|---|
| 点赞 | 登录用户可点赞 / 取消点赞 |
| 收藏 | 登录用户可收藏 / 取消收藏 |
| 下载 | 下载原图，记录下载次数 |
| 浏览量 | 访问详情页自动计数（异步聚合） |

### 3.5 后台管理（V2）

首期不实现，预留扩展：

- 壁纸审核（上架 / 下架）
- 用户管理（封禁 / 解封）
- 数据统计面板（上传量、下载量、活跃用户）

## 4. 壁纸状态流转

```
上传中(uploading) → 处理中(processing) → 已发布(published)
                                       → 处理失败(failed)
已发布(published) → 已下架(removed)
```

| 状态值 | 含义 |
|---|---|
| 0 | processing -- 图片正在异步处理 |
| 1 | published -- 正常展示 |
| 2 | failed -- 处理失败 |
| 3 | removed -- 已删除/下架 |

## 6. 非功能需求

| 项 | 要求 |
|---|---|
| 图片格式 | JPG / PNG / WebP |
| 单文件大小 | 最大 20MB |
| 缩略图 | 300x200，WebP 格式 |
| 预览图 | 宽 800px 等比缩放，WebP 格式 |
| 响应时间 | 列表接口 < 200ms（缓存命中） |
| 并发 | 支持 100 并发用户 |
| 部署 | Docker Compose 一键部署 |
